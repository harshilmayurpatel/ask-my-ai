# Projects

## Ask my AI (this chat assistant)
The assistant answering these questions is one of Harshil's projects. It is a retrieval-augmented generation (RAG) chat built with LangChain, FAISS for vector search, FastEmbed for embeddings, and FastAPI for a streaming API, packaged with Docker and deployed on Render. Answers are generated by GPT-OSS 120B, an open-weight model served by Groq, using only facts retrieved from Harshil's resume and project notes. The code is at github.com/harshilmayurpatel/ask-my-ai.

## NBA 2024-2025 Data Scraping and Statistical Analysis
A Python web scraper built with Requests and BeautifulSoup that extracts real-time NBA statistics, built collaboratively. The data feeds 18+ visualizations made with Matplotlib and Seaborn, analyzing performance trends and statistical insights. Modular automation reduced redundancy by over 80% and cut execution time to under 30 seconds. It also has a Streamlit app. Tools: Python, BeautifulSoup, Pandas, Matplotlib, Seaborn, Streamlit.

## Electric Vehicle Market Analysis
An interactive Tableau dashboard built on 150,413 electric vehicle registration records: growth by model year, state-level maps, top makers and models, CAFV incentive eligibility, and BEV vs. PHEV distribution. Key findings: registrations peak at about 37,100 for model year 2023; battery electric vehicles are 77.6% of the fleet; Tesla alone is 52.7%; the average electric range is 67.8 miles. He cleaned the data in Excel (model years 2010 onward, missing ranges removed, BEV and PHEV labels standardized) and published the dashboard on Tableau Public. Tools: Tableau, Excel, data cleaning.

## AI Puzzle Solver: Sokoban game
A retro, pixel-art Sokoban puzzle game that runs in the browser (play it at harshilmayurpatel.github.io/Sokoban-AI-Solver), with a built-in AI solver that can show a hint or play the level out. The solver offers three search algorithms: A* (the default, short solutions while exploring few states), Breadth-First Search (fewest pushes) and Depth-First Search (finds a valid path fast). It searches over push states, prunes dead squares and frozen-crate deadlocks, and runs in a Web Worker so the game never freezes. 12 original levels, each verified solvable; A* solves the hardest in 18 pushes after exploring about 700 states. Tools: JavaScript, HTML, CSS, search algorithms (A*, BFS, DFS).
