# Projects

## Ask my AI (this chat assistant)
The assistant answering these questions is one of Harshil's projects. It is a retrieval-augmented generation (RAG) chat built with LangChain, FAISS for vector search, FastEmbed for embeddings, and FastAPI for a streaming API, packaged with Docker and deployed on Render. Answers are generated by Llama 3.3 70B through Groq, using only facts retrieved from Harshil's resume and project notes. The code is at github.com/harshilmayurpatel/ask-my-ai.

## NBA 2024-2025 Data Scraping and Statistical Analysis
A Python web scraper built with Requests and BeautifulSoup that extracts real-time NBA statistics, built collaboratively. The data feeds 18+ visualizations made with Matplotlib and Seaborn, analyzing performance trends and statistical insights. Modular automation reduced redundancy by over 80% and cut execution time to under 30 seconds. It also has a Streamlit app. Tools: Python, BeautifulSoup, Pandas, Matplotlib, Seaborn, Streamlit.

## Electric Vehicle Market Analysis
An interactive Tableau dashboard analyzing electric vehicle adoption across the U.S.: growth trends, state-level adoption maps, and BEV vs. PHEV distribution, with KPI tracking and a clean data-preparation pipeline. Tools: Tableau, Excel, data cleaning.

## AI Puzzle Solver: Sokoban game
An AI-powered Sokoban puzzle game that uses the Depth-First Search (DFS) algorithm to find valid solution paths, with an intelligent hint mechanism to help players and improve retention. Tools: Python, HTML, CSS, search algorithms.

## Travel Buddy
An Android app that helps tourists navigate locations, calculate distances, and get real-time route information, with Google Maps API integration for location tracking and dynamic travel planning. Tools: Android Studio, Java, Google Maps API.

## VR Game Development
Immersive multiplayer VR games, including Spaceship Shooting and Tennis, built in Unity3D with C#. They feature realistic physics-based interactions and AI-driven opponents, with work on rendering performance and frame rates for a smoother VR experience. Tools: Unity3D, C#, Blender.
